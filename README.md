# Oracle PC Status - Android App (Mobile)

스마트폰에서 언제 어디서나 오라클 서버와 포트 상태를 즉시 모니터링할 수 있는 React Native 기반의 모바일 어플리케이션입니다.

## ✨ 주요 기능
- **모던 다크 테마 UI**: 모바일 환경에 최적화된 매우 세련되고 깔끔한 딥 다크 테마(Deep Dark Theme)를 채택하여 가독성을 높였습니다. 스와이프 제스처를 지원합니다.
- **맞춤형 포트 모니터링**: 개별 서버마다 마인크래프트 포트나 RDP 포트 등을 무제한 등록하고 즉각 상태를 점검할 수 있습니다.
- **백그라운드 자동 갱신 (제한적)**: 모바일 앱 특성 상 스마트폰이 재부팅되어도 안드로이드 시스템의 Background Fetch 스케줄러가 백그라운드에서 동작하도록 설계되어 있습니다. (단, 제조사 배터리 최적화 설정에 따라 동작이 지연될 수 있습니다. 중요한 모니터링 시 앱을 직접 열어주세요.)
- **최저 사양 서버 최적화**: 30초 이상의 넉넉한 딜레이를 주어 오라클 클라우드 프리티어 서버에 부하를 주지 않습니다.

## 📱 빌드 및 설치 방법 (APK 추출)

본 앱은 React Native 스캐폴딩으로 구성되어 있습니다. 로컬에서 APK를 뽑으려면 Android Studio와 Java(JDK)가 필요합니다.

1. **의존성 설치**
   ```cmd
   npm install
   ```

2. **개발 모드로 휴대폰에서 바로 테스트하기 (Expo / Metro)**
   ```cmd
   npm start
   ```

3. **APK 파일 빌드하기 (GitHub Actions 권장)**
   - 개인 PC에서 환경 세팅이 까다로울 수 있습니다!
   - 깃허브(GitHub)에 이 코드를 올리시고 `EAS Build`나 `GitHub Actions`를 통해 클라우드에서 `.apk` 파일을 자동 생성하도록 구성하시는 것을 가장 추천드립니다.
   - 로컬에서 강제 빌드할 경우: 안드로이드 스튜디오 설치 후 `android/` 폴더에서 `./gradlew assembleRelease` 명령어를 치시면 됩니다.
